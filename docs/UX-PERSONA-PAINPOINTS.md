## 0. 한 줄 요약

Wave E 이후 **전이 언어·CTA 위계·콜드「첫 따라가기」·AuthGate 카피**는 실측으로 확인됐다.  
지금 루프를 막는 것은 (1) **지도 베이스맵 공백**, (2) **데모/콜드 계정에서 P2·P4 실행함이 텅 비어 다음 행동이 안 보이는 것**, (3) **콘텐츠 신뢰(사진↔태그·스펙 불일치)**, (4) **통계/플래너에 남은 ‘여행·일기’ 멘탈모델 잔상**이다.

## 1. 페르소나 요약

| ID | 이름 | 한 줄 정의 | 성공 순간 | 주요 화면 |
|----|------|------------|-----------|-----------|
| **P1** | 탐색러 | 공개 코스를 **쇼핑**해 따라갈 동선을 고른다 | 카드/지도에서 1초 만에 “갈 만한 코스”로 확신 → 따라가기 | `/` · 지도 · 상세 · AuthGate |
| **P2** | 따라가이 | 복제한 초안을 **다듬고 다녀온다** | 보관함「따라가는 중」→ 다듬기 → `다녀왔어요` | 따라가기 시트 · 플래너 · 보관함 · 완주 |
| **P3** | 코스 메이커 | 남이 따라갈 **동선을 만들고 공개**한다 | FAB→작성→공개 게이트→책장/통계에 전이 지표 | FAB · `/routes/new` · 프로필 · `/u/[handle]` |

## 2. 페르소나별 10점 시나리오 (점검 스크립트)

채점 축: **발견 / 전이 명확성 / 신뢰·안전 / 북스타 루프** (각 1–10, 종합=평균).

### P1 — 탐색러

1. 게스트로 `/` 진입 → 정렬·필터·카드 SpecLine·TransferPill 확인  
2. 지도 탭 → 베이스맵·peek 스펙  
3. 카드 → 상세 → `이 코스 따라가기` → AuthGate  
4. 로그인 후 동일 코스 → 목적 시트(계획/기록)까지 (복제 실행은 읽기 전용으로 중지)

### P2 — 따라가이

1. 따라가기 시트 카피·목적 선택 게이팅  
2. 보관함「따라가는 중」진행 카드·체크리스트  
3. 초안 플래너 재진입 / 원본 `다녀왔어요` 톤  
4. *(데모 계정에 복제본 없으면 empty로 한계 기록)*

### P3 — 코스 메이커

1. FAB → 기록 5스텝 / 계획 지도 플래너 empty  
2. 소유 상세 영향력 빈 상태  
3. `/profile` 전이 지표 · `/profile/stats` 카피  
4. `/u/[handle]` 책장 + 팔로우 CTA

### P4 — 영향력 구독자

1. 메이커 책장 → `팔로우`  
2. 보관함「팔로잉」`새 코스` / `사람`  
3. 홈 팔로잉 레일 · `/notifications`  
4. *(팔로우 0이면 배달 루프 실측 불가 — empty 카피로 평가)*

**재현 명령**

```bash
AUDIT_BASE_URL=https://course-sns.vercel.app \
  pnpm exec playwright test --config=playwright.audit.config.ts
```

1. 팔로잉 empty 기본을「사람」이 아니라 **추천 메이커/둘러보기**로
