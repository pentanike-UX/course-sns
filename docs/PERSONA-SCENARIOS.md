# Coursee 페르소나별 시나리오

> 기준: course-sns MVP `v0.3.8+` · 프로덕션 https://course-sns.vercel.app  
> 웹 가이드: `/deliverables/scenarios`  
> 연계: [`COURSE-UX-DESIGN.md`](COURSE-UX-DESIGN.md) · [`BRAND.md`](BRAND.md) · [`UX-PERSONA-PAINPOINTS.md`](UX-PERSONA-PAINPOINTS.md)

**북스타 루프:** 발견 → 따라가기 → 다녀왔어요 → 영향력(복제·완주·팔로우)

이 문서는 **현재 배포된 기능으로 실제로 밟을 수 있는** 페르소나 시나리오입니다.  
설계 목표·페인포인트는 UX 문서에, 여기는 **검증·온보딩·데모 스크립트**용 정본입니다.

## 0. 페르소나 한눈에

| ID | 이름 | 한 줄 목표 | 주 화면 | 성공 신호 |
|----|------|------------|---------|-----------|
| **P1** | 탐색러 | 따라갈 만한 코스를 고른다 | 홈 `/` · 지도 · 상세 | 상세 → 따라가기 |
| **P2** | 따라가이 | 초안을 다듬고 실제로 다녀온다 | 보관함「따라가는 중」 | 다녀왔어요 완료 |
| **P3** | 코스 메이커 | 남이 따라갈 동선을 공개한다 | FAB · 작성 · 책장 | 공개 + 따라감/다녀옴 |
| **P4** | 영향력 구독자 | 믿을 메이커의 새 코스를 받는다 | 책장 · 구독 코스 | 팔로우 → 따라가기 |
| **G** | 게스트(첫 방문) | 가입 없이 가치를 확인한다 | 홈 · 상세 · 책장 | AuthGate 전 열람 |

데모 계정(있을 때): `demo@course-sns.app` / `demo1234`

## G — 게스트 첫 방문 (가입 전)

**맥락:** SNS 링크·검색으로 처음 들어옴. 가입 전에 “따라가는 앱인지”를 확인하고 싶다.

| 단계 | 행동 | 화면 | 기대 결과 |
|------|------|------|-----------|
| G1 | 랜딩 진입 | `/` | 공개 코스 쇼핑 피드. 스플래시 후 coursee 브랜드 |
| G2 | 정렬·필터 훑기 | 홈 칩 / 필터 시트 | 최신·많이 따라간·많이 다녀온·가까운 / 지역·누구와·난이도 |
| G3 | 카드 탭 | `/routes/[id]` | 스펙·전이(따라감/다녀옴) 위주 상세. 좋아요는 보조 |
| G4 | 지도로 고르기 | `/?mode=map` | 핀·클러스터·peek에 스펙+전이 |
| G5 | 메이커 책장 | `/u/[handle]` | 공개 코스 목록·팔로우 버튼 노출 |
| G6 | 따라가기 시도 | 상세 CTA | **AuthGate** — “따라가려면 로그인” 유도 |

**성공:** 로그인 없이 가치(동선·전이 프루프)를 이해했고, 쓰기 직전에만 막힌다.  
**실패:** 홈이 좋아요·일기처럼 보이거나, 열람까지 로그인을 강요한다.

## P1 — 탐색러 (발견 → 따라가기)

**맥락:** 주말에 갈 동선이 필요함. “사진 맛집 한 컷”보다 **순서·이동·난이도**가 있는 코스를 원한다.

**사전 조건:** 게스트 또는 로그인. 따라가기 직전 로그인 필요.

### Happy path

| 단계 | 행동 | 화면 / UI | 기대 결과 |
|------|------|-----------|-----------|
| 1 | 홈에서 코스 쇼핑 | `/` | 카드에 실행 스펙 + 따라감/다녀옴 |
| 2 | 필터: 지역 → 누구와 → 난이도 | 필터 시트 | 감정·테마보다 실행 조건이 위 |
| 3 | 정렬「많이 따라간」또는「많이 다녀온」 | 정렬 칩 | 전이 지표로 신뢰도 확인 |
| 4 | (선택) 지도로 위치감 확인 | `/?mode=map` | peek = 스펙 + 전이 (♥ 아님) |
| 5 | 상세에서 동선·팁 스캔 | `/routes/[id]` | Primary CTA = 따라가기 |
| 6 | 「이 코스 따라가기」→ 계획 | AuthGate → 복제 | **비공개 초안** 생성 |
| 7 | 가져왔어요 가이드 / next-step | 초안·편집 | 보관함「따라가는 중」으로 이어짐 |

### 변형

| ID | 상황 | 경로 |
|----|------|------|
| P1-a | 일단 찜만 | 상세「저장」→ 보관함「저장」→ 나중에「따라가기」 |
| P1-b | 구독 메이커 신작 | 홈「구독 중인 새 코스」레일 → 상세 → 따라가기 |
| P1-c | 콜드 코스(전이 0) | `첫 따라가기` 등 전이 카피 노출 — 좋아요 폴백에 의존하지 않음 |

**성공 지표:** Discovery→Detail, Detail→Copy  
**검증 포인트:** 제목 가리고도 “따라갈 동선”으로 읽히는지(1초 테스트).

## P2 — 따라가이 (복제 → 다듬기 → 다녀왔어요)

**맥락:** 이미 따라간 초안이 있다. 일정에 맞게 스팟을 조금 고치고, 다녀온 뒤 다음 사람을 위한 팁을 남긴다.

**사전 조건:** 로그인 + `route_copies`로 가져온 초안 1개 이상.

### Happy path

| 단계 | 행동 | 화면 / UI | 기대 결과 |
|------|------|-----------|-----------|
| 1 | 보관함 열기 | `/library` | 세그먼트「따라가는 중」기본/진입 |
| 2 | 진행 중 코스 선택 | 따라가는 중 카드 | 진행 체크리스트(스팟·이동·다녀왔어요) |
| 3 | 초안 다듬기 | `/routes/[id]/edit` | 스팟 순서·이동·시간 조정, 임시저장/완료 |
| 4 | 실제 방문 후 원본 또는 내 코스 상세 | `/routes/[id]` | CTA「다녀왔어요」(톤 사다리) |
| 5 | 별점 + 한 줄 팁 | 완주 시트 | completion 반영 → 원본 프루프 증가 |
| 6 | (선택) 후기 수정 | 같은 CTA 계열 | 「후기 수정」neutral 톤 |

### 변형

| ID | 상황 | 경로 |
|----|------|------|
| P2-a | 다듬지 않고 바로 완주 | 따라가는 중 → 원본 상세 → 다녀왔어요 |
| P2-b | 중간에 이탈 후 재진입 | 보관함에서 체크리스트로 “다음에 할 일” 재확인 |
| P2-c | 저장만 해 둔 코스 | 보관함「저장」→ 카드「따라가기」→ P2 happy path로 합류 |

**성공 지표:** Copy→Completion  
**검증 포인트:** CTA 상태(미복제 / 복제·미완주 / 완주)가 라벨·톤으로 구분되는지.

## P3 — 코스 메이커 (작성 → 공개 → 영향력)

**맥락:** 직접 다녀온(또는 계획한) 동선을 **남이 따라갈 수 있게** 구조화해 올리고, 반응이 전이 지표로 보이길 원한다.

**사전 조건:** 로그인.

### Happy path — 기록(회고)

| 단계 | 행동 | 화면 / UI | 기대 결과 |
|------|------|-----------|-----------|
| 1 | FAB(+) | 바텀시트 | 「코스 기록하기」선택 |
| 2 | 위자드 진행 | `/routes/new` | 스팟·사진·이동·추천·난이도 |
| 3 | 따라가기 준비도 확인 | soft hint | 지역·추천·난이도·스팟≥2 등 |
| 4 | 공개/비공개 명시 선택 | 공개 게이트 | 실수 공개 방지 |
| 5 | 완료 후 책장·내 코스 | `/u/[me]` · 드로어 | 공개 코스가 책장에 노출 |
| 6 | 영향력 확인 | `/profile/stats` · 알림 | 따라감·다녀옴·팔로워 (좋아요는 하위) |

### Happy path — 계획(앞으로 갈 동선)

| 단계 | 행동 | 기대 결과 |
|------|------|-----------|
| 1 | FAB → 「코스 계획하기」 | 지도 플래너 멘탈모델 |
| 2 | 스팟·이동 배치 후 저장 | 계획 코스(비공개 가능) |
| 3 | 다듬은 뒤 공개 | P3 기록 경로와 동일 게이트 |

### 변형

| ID | 상황 | 경로 |
|----|------|------|
| P3-a | 비공개로만 보관 | 공개 게이트에서 비공개 — 책장 미노출 |
| P3-b | 누군가 따라감 | 알림「따라갔어요」·통계 증가 → 메이커 동기 |
| P3-c | 다녀옴 후기 유입 | 원본 상세 후기 섹션 + completion 지표 |

**성공 지표:** 코스당 copy_count, completions per copy, 메이커당 public 코스 수  
**검증 포인트:** 게시 전 “따라가기 쉬운가” 힌트와 공개 선택이 빠지지 않는지.

## P4 — 영향력 구독자 (팔로우 → 스트림 → 따라가기)

**맥락:** 특정 메이커의 동선 감각을 신뢰한다. 피드 전체를 훑기보다 **구독한 사람의 새 코스**를 받고 싶다.

**사전 조건:** 로그인. 팔로우할 메이커 1명 이상 권장.

### Happy path

| 단계 | 행동 | 화면 / UI | 기대 결과 |
|------|------|-----------|-----------|
| 1 | 상세 또는 카드에서 작성자 진입 | `/u/[handle]` | 책장 = 그 사람의 코스 선반 |
| 2 | 팔로우 | Follow 토글 | 맞팔 시 라벨 구분 |
| 3 | 보관함「구독 코스」 | `/library?tab=subscribed` | **새 코스 스트림**이 사람 관리보다 우선 |
| 4 | (또는) 홈 레일 | `/` 구독 레일 | 데이터 있을 때 신작 노출 |
| 5 | 새 코스 알림 | `/notifications` | 전이·구독 그룹이 좋아요·댓글보다 위 |
| 6 | 상세 → 따라가기 | P1 6–7단계와 동일 | P4 → P2로 역할 전환 |

### 변형

| ID | 상황 | 경로 |
|----|------|------|
| P4-a | 사람 관리 | 구독 코스「팔로우 관리」또는 프로필 following 목록 |
| P4-b | 언팔 후 스트림 정리 | 구독 코스에서 해당 메이커 신작 감소 |
| P4-c | 맞팔 메이커 | 라벨로 관계 인지 → 책장 재방문 |

**성공 지표:** Follow→Copy (스트림/책장 경유)  
**검증 포인트:** 보관함이 “좋아요함”이 아니라 **실행함+구독함**으로 읽히는지.

## 교차 시나리오 — 북스타 end-to-end

한 데모로 루프 전체를 보여줄 때:

```text
[메이커 P3] FAB로 공개 코스 작성
    → [구독자 P4] 책장 팔로우
    → [탐색러 P1] 홈/스트림에서 발견 · 따라가기
    → [따라가이 P2] 보관함에서 다듬기 · 다녀왔어요
    → [메이커 P3] 알림·통계에서 따라감/다녀옴 확인
```

| 체크 | 확인 |
|------|------|
| 언어 | 사용자 노출면「코스」— 일기/루트 잔상 없음 |
| 위계 | 전이 CTA > 저장/좋아요 |
| 게스트 | 열람 OK · 쓰기 AuthGate |
| 브랜드 | 스플래시·헤더·로그인 coursee 락업 |

## 역할 전환 맵

| From → To | 트리거 |
|-----------|--------|
| G → P1 | 로그인 후 쇼핑 계속 |
| P1 → P2 | 따라가기 성공 |
| P2 → P3 | FAB로 내 코스 작성 |
| P1/P2 → P4 | 메이커 팔로우 |
| P4 → P2 | 구독 코스 따라가기 |
| P3 → (영향) | 타인 copy/completion |

한 사용자가 여러 페르소나를 **같은 계정에서 순차 수행**하는 것이 정상이다. 화면마다 주인공 페르소나는 하나다.

## 데모·QA 스크립트 (짧은 버전)

1. **게스트:** `/` → 필터 → 상세 → 따라가기 → AuthGate  
2. **P1:** 로그인 →「많이 따라간」→ 따라가기 → 초안 생성  
3. **P2:** `/library` 따라가는 중 → 체크리스트 → 다녀왔어요  
4. **P3:** FAB 기록 → 준비도·공개 선택 → `/profile/stats`  
5. **P4:** `/u/[handle]` 팔로우 → 구독 코스/홈 레일 → 따라가기  

소요: 기능 익숙한 기준 약 10–15분.
