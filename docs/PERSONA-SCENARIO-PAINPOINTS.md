## G · P1 — 게스트 / 탐색러

### MAP-01 — 지도 필터 일부 미적용
| | |
|--|--|
| **단계** | G2 / P1-2 · 지도에서 누구와·난이도 필터 |
| **심각도** | P0 · **사용실패** |
| **파일** | `FeedMap.tsx` (`filterSig`) |
| **현상** | `filterSig`가 `themes\|moods\|regions`만 포함 → `purposes`·`difficulties` 변경 시 핀 재조회 안 함 |
| **체감** | 필터를 켰는데 지도 결과가 그대로 → “앱이 고장” |
| **개선** | `filterSig`에 전 필터 필드 포함 |

### MAP-02 — 지도 시트에 따라가기 없음
| | |
|--|--|
| **단계** | G4 / P1-4→6 |
| **심각도** | P1 · **사용실패** |
| **파일** | `RouteDetailSheet.tsx` |
| **현상** | Primary가 「전체 페이지에서 보기」뿐. `CopyRouteButton`/AuthGate 경로 없음 |
| **체감** | 지도에서 골랐는데 따라가려면 상세를 한 번 더 열어야 함 |
| **개선** | 시트에 「이 코스 따라가기」추가 |
