# 인수 기준

경로 PR은 아래를 통과해야 한다. 키 없는 환경에서는 “키 없으면 폴백/커넥터”만 확인하고, 실키 검증을 체크리스트에 남긴다.

## 국내

- [ ] `TMAP_APP_KEY` 있음: 도보 레그가 보행로. 강변/공원에서 차도와 갈라지는지.
- [ ] 키 없음: 도보는 예전처럼 driving 폴백. 앱이 크래시하지 않음.
- [ ] 자가용: 네이버 도로. (회귀)
- [ ] 지하철: Transit/ODsay 전에는 점선. **자동차 도로가 아님.**
- [ ] B 또는 C 후: 버스·지하철 선이 도로 한복판이 아닌 노선/역 동선에 가깝다.
- [ ] 제주 스팟 쌍은 국내 스택 (bbox). 후쿠오카는 해외.

## 해외

- [ ] 파리(또는 도쿄) 도보·자전거·자가용·버스·지하철·기차 레그 각각, **모든 연속 쌍**에 구글 폴리라인.
- [ ] 타일이 구글 Maps JS. 네이버 빈 타일/오류 오버레이가 아님.
- [ ] `other`만 커넥터.
- [ ] 키 없음: 크래시 없이 커넥터 + 안내 가능한 폴백. 출시 완료로 치지 않음.
- [ ] 국내 서울 코스 상세가 구글 타일로 바뀌지 않음.
